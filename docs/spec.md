# 仕様書

アプリの「何を・どう動かすか」を書く。AIは作業の前に必ずここを読む。

## 目的

飲み会の割り勘を、先輩・後輩の傾斜つきで1分で決めて、LINEにそのまま貼れる文面にしてくれるWebアプリ。（元のメモ：飲み会の割り勘を、先輩・後輩の傾斜つきで1分で決めて、LINEに貼れる文面にするWebアプリ）

## 前提

- 使う人・使う場面（デザイン担当の分析。推定を含む）：
  - 使う人：飲み会の幹事をする若手の会社員・大学のサークルの幹事。上司・先輩・後輩が混ざった会で、誰がいくら払うかを決めて集金する人
  - 使う場面：店を出る前や帰りの電車で、会計の伝票を見ながらスマホ片手に1分で決め、LINEのグループにそのまま貼る（開くのは会計のときの1回）
  - 受け取る人：文面のURLを開いた参加者が、自分の区分を押して金額だけを確かめる
- 技術：Next.js（App Router）＋TypeScript、テストはVitest

## 画面

（ページごとに、何を出して何ができるか）

### 前回の会計の記憶（`/`）

- 覚える物：会の名前・合計金額・区分ごとの人数・倍率・単位・端数の持ち方・幹事の名前。直近の1件だけ。端末の `localStorage`（1つのキー）に JSON で残し、どこにも送らない
- 保存：値が変わるたびに自動で保存する（保存ボタンは無い）
- 戻す条件：URL に会計の query（`t`）が無い `/` を開いたときだけ、マウント後に保存した値で画面（合計金額の入力欄の表示も）を戻す。保存が無い端末では、既定の会計（部署の忘年会 48,600円）のまま
- URL に会計の query があるとき（`/?t=...`、文面の URL）と `/r?...` では、保存した値で上書きしない。開いた値で保存も上書きしない
- 読み込みの直し方：壊れた JSON・オブジェクトでない物は捨てる（何も戻さない）。項目ごとに、型が違えば既定の値、範囲外なら範囲内に直す（人数 0〜99、倍率は 1.0〜3.0、単位は 10/100/500/1000 のどれか、会の名前 30字、幹事の名前 20字）
- `localStorage` が使えない（例外）ときも、画面は壊さず、そのまま動く
