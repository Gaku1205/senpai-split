# 仕様書

アプリの「何を・どう動かすか」を書く。AIは作業の前に必ずここを読む。

## 目的

飲み会の割り勘を、先輩・後輩の傾斜つきで1分で決めて、LINEにそのまま貼れる文面にしてくれるWebアプリ。（元のメモ：飲み会の割り勘を、先輩・後輩の傾斜つきで1分で決めて、LINEに貼れる文面にするWebアプリ）

## 前提

- 使う人・使う場面（デザイン担当の分析。推定を含む）：
  - 使う人：飲み会の幹事をする若手の会社員・大学のサークルの幹事。上司・先輩・後輩が混ざった会で、誰がいくら払うかを決めて集金する人
  - 使う場面：店を出る前や帰りの電車で、会計の伝票を見ながらスマホ片手に1分で決め、LINEのグループにそのまま貼る（開くのは会計のときの1回）
  - 受け取る人：文面のURLを開いた参加者が、自分の区分を押して金額だけを確かめる
- 技術：Next.js（App Router）＋TypeScript、テストはVitest
